# StyleX Variants

Typed, compile-time variants for [StyleX](https://stylexjs.com/), inspired by
[Tailwind Variants](https://www.tailwind-variants.org/).

StyleX Variants lets you define base styles, named variants, defaults and
compound variants while keeping the selected props type-safe.

## What is included?

- Static StyleX styles compiled by Babel.
- Type-safe variant selections with TypeScript.
- Boolean variants and compound variants.
- Merging of generated props with `className` and `style`.
