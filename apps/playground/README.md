# StyleX Variants playground

This app is a consumer-style Vite example for `@stylex-variants/core`. It
shows the supported recipe APIs in one place: variants, boolean and compound
variants, overrides, `extend`, slots, and `compoundSlots`.

From the repository root:

```sh
pnpm install
pnpm dev:playground
```

To validate the production bundle:

```sh
pnpm --filter playground build
```
